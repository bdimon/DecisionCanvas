# DecisionCanvas — Выбор решения из двух вариантов

> Интеллектуальное веб-приложение и Progressive Web App (PWA) для взвешенного сравнительного анализа двух альтернатив. Позволяет структурировать принятие сложных решений через списки «За» и «Против», многокритериальную матрицу оценок, SWOT-анализ и синтез итогового вердикта.

---

## 📌 Основные возможности

1. **Глубокий сравнительный анализ**:
   - **Списки «За» и «Против» (Pros & Cons)**: ранжирование аргументов по весам (от 1 до 5) и категориям (Финансы, Время, Риски, Развитие и др.).
   - **Многокритериальная таблица сравнения**: детализированная шкала (1–10) с настраиваемыми весами критериев и автоматическим взвешенным подсчетом баллов.
   - **Матрица SWOT-анализа**: оценка сильных сторон, уязвимостей, возможностей и скрытых угроз для обоих вариантов.
   - **Стратегический вердикт**: расчет индекса уверенности (0–100%), ключевые драйверы выбора, анализ компромиссов (trade-offs) и пошаговый план внедрения.

2. **Отказоустойчивый гибридный движок**:
   - **AI-анализ через Google Gemini API**: поддержка каскадного переключения моделей (`gemini-3.8-flash`, `gemini-3.1-flash-lite`, `gemini-flash-latest`) для защиты от пиковых нагрузок (503/429).
   - **Автономный экспертный генератор**: при отсутствии интернета или недоступности API приложение автоматически формирует структурированный анализ без зависаний.

3. **Progressive Web App (PWA) и офлайн-режим**:
   - Поддержка установки на **Android**, **iOS (Safari)** и **Desktop** (Chrome, Edge) в режиме Standalone без адресной строки браузера.
   - Полный набор иконок (192×192, 512×512, адаптивные maskable-иконки, Apple Touch Icon).
   - Индикатор статуса сети и работа в офлайне с кэшированием статических ресурсов через Workbox.

4. **Экспорт и адаптивность**:
   - Адаптивный интерфейс для смартфонов, планшетов и десктопов.
   - Версия для печати и экспорта в PDF со специальными `@media print` стилями.

## 🚀 Быстрый старт

### Требования
- Node.js 20+
- npm, pnpm или bun

### 1. Клонирование и установка зависимостей
```bash
git clone https://github.com/your-username/decision-canvas.git
cd decision-canvas
npm install
```

### 2. Настройка переменных окружения
Создайте файл `.env` на основе примера `.env.example`:
```bash
cp .env.example .env
```

Укажите ваш ключ Gemini API (опционально, при отсутствии ключа работает встроенный аналитический движок):
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. Запуск в режиме разработки
```bash
npm run dev
```
Приложение откроется по адресу: `http://localhost:3000`

### 4. Сборка для продакшна
```bash
npm run build
npm start
```

## 📱 Установка PWA на устройства

- **Android (Chrome / Яндекс / Edge)**: нажмите кнопку «Установить» в шапке сайта либо пункт меню браузера *«Установить приложение»*.
- **iOS (Safari)**: нажмите кнопку *«Поделиться»* (значок квадрата со стрелкой) в нижней панели и выберите *«На экран „Домой“»*.
- **Десктоп (Chrome, Edge)**: значок установки отображается в адресной строке и в шапке приложения.
