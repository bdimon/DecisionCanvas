# DecisionCanvas — Выбор решения из двух вариантов

> Интеллектуальное полнофункциональное веб-приложение и Progressive Web App (PWA) для взвешенного сравнительного анализа двух альтернатив. Помогает преодолеть паралич выбора и структурировать принятие сложных решений через взвешенные списки «За» и «Против», многокритериальную матрицу оценок, SWOT-анализ, динамический синтез и редактирование итогового вердикта.

---

## 📌 Основные возможности

### 1. Глубокий сравнительный анализ (4 аналитических слоя)
- **Списки «За» и «Против» (Pros & Cons)**:
  - Ранжирование аргументов по весам важности (от 1 до 5).
  - Тематическая категоризация (Финансы, Время, Риски, Развитие, Комфорт и др.).
  - Автоматический подсчет чистого баланса сил между альтернативами.
- **Многокритериальная таблица сравнения (Decision Matrix)**:
  - Детализированная оценка критериев по шкале 1–10.
  - Настраиваемые веса важности параметров (1–5) с пропорциональным распределением долей.
  - Динамический пересчет итоговых процентов лидерства в реальном времени.
- **Матрица SWOT-анализа**:
  - Структурированный аудит сильных сторон (Strengths), уязвимостей (Weaknesses), возможностей (Opportunities) и скрытых рисков/угроз (Threats) для обоих вариантов.
- **Стратегический вердикт и синтез**:
  - Расчет индекса уверенности выбора (0–100%).
  - Ключевые драйверы превосходства (Key Drivers).
  - Честный анализ компромиссов и издержек упущенной выгоды (Trade-off Summary).
  - Пошаговый практический план действий (Next Steps).
  - Возможность **ручного редактирования вердикта** с сохранением базовой копии для мгновенного отката к оригиналу.

---

### 2. Двухуровневое хранилище (LocalStorage + IndexedDB)
- **Мгновенный отклик и кэширование**: оперативное состояние сессии, активная вкладка и черновики форм синхронизируются с `LocalStorage`.
- **IndexedDB Fallback (база `decision_lens_idb`)**:
  - При переполнении квоты браузера (`QuotaExceededError`) данные автоматически перенаправляются в IndexedDB.
  - Практически неограниченный объем для хранения истории принятых решений.
  - Фоновая двусторонняя синхронизация `syncHistoryWithIndexedDB()` восстанавливает полную историю при запуске, даже если кэш `LocalStorage` был усечен или очищен браузером.
- **Интерактивная история решений (`HistoryModal.tsx`)**:
  - Просмотр ранее сохраненных дилемм с отображением даты, счета и победителя.
  - Мгновенное переключение на любой анализ из истории, удаление отдельных записей или полная очистка.

---

### 3. Интернационализация (i18n: RU / EN)
- Полная двуязычная локализация пользовательского интерфейса: **Русский** и **English**.
- **Восстановление языка при инициализации**: чтение ключа `decision_canvas_lang` из хранилища гарантирует запуск интерфейса и генерацию начального пресета на выбранном языке.
- **Контроль языкового соответствия вердикта**: если кастомный вердикт был отредактирован на одном языке, а интерфейс переключен на другой, выводится предупреждение с кнопкой мгновенного пересчета и адаптации на активный язык.

---

### 4. Отказоустойчивый гибридный движок и честный Offline-First
- **Явная проверка `navigator.onLine`**:
  - Если устройство находится вне сети, приложение не ожидает таймаутов сетевых запросов, а мгновенно генерирует экспертный анализ через встроенный детерминированный движок.
  - Пользователю выводится понятное системное уведомление о работе в автономном режиме.
- **AI-генерация через Google Gemini API**:
  - Интеграция с официальным SDK `@google/genai` (Node.js 22 LTS).
  - Каскадный fallback моделей (`gemini-3.8-flash` → `gemini-3.1-flash-lite` → `gemini-flash-latest`) для защиты от пиковых нагрузок и ошибок 503/429.
  - Клиентский таймаут безопасности (35 с) с поддержкой ручной отмены запроса (`AbortController`).
  - Серверная оптимизация ресурсов: при разрыве соединения со стороны клиента (`req.on('close')`) генерация и перебор моделей немедленно прекращаются.

---

### 5. Progressive Web App (PWA) и адаптивность
- **Standalone PWA**:
  - Установка как нативного приложения на **Android**, **iOS (Safari)** и **Desktop** (Chrome, Edge).
  - Полноценный оффлайн-кэш статических ресурсов через Service Worker (Workbox).
  - Полный комплект адаптивных иконок (192×192, 512×512, maskable safe-area, Apple Touch Icon).
- **Виртуальный эмулятор Android (`AndroidVirtualDevice.tsx`)**:
  - Встроенный интерактивный фрейм смартфона прямо в десктопном интерфейсе для удобного тестирования мобильного UX.
- **Версия для печати**:
  - Оптимизированные стили `@media print` для экспорта готового отчета в PDF или вывода на принтер без интерфейсного шума.

## 🚀 Быстрый старт

### Требования
- **Node.js 22+** (рекомендуется v22.23.2 или выше)
- npm, pnpm или bun

### 1. Клонирование и установка зависимостей
```bash
git clone https://github.com/your-username/decision-canvas.git
cd decision-canvas
npm install
```

### 2. Настройка переменных окружения
Создайте файл `.env` в корне проекта (по шаблону `.env.example`):
```bash
cp .env.example .env
```

Укажите ключ Gemini API (опционально; при отсутствии ключа или в оффлайне приложение полноценно функционирует на встроенном аналитическом движке):
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### 3. Запуск в режиме разработки
```bash
npm run dev
```
Dev-сервер запустится на порту 3000: `http://localhost:3000`

### 4. Проверка типов и линтинг
```bash
npm run lint
```

### 5. Сборка и запуск в продакшн
```bash
npm run build
npm start
```

## 📜 Соглашение и хронология разработки

В проекте строго соблюдается стандарт **Conventional Commits**:

1. **`feat(core): initial decision analysis engine with weighted pros/cons and comparison table`**
   - Реализация интерфейсов и моделей взвешенного скоринга (1–5 для Pros/Cons, 1–10 для критериев).
   - Разработка 4 квадрантов SWOT-анализа и синтезатора вердикта с оценкой уверенности.
   - Подключение детерминированного локального генератора для автономной работы.

2. **`feat(ai): integrate Gemini API with cascade fallback model handling`**
   - Express-сервер с изоляцией API-ключей на стороне бэкенда.
   - Официальный SDK `@google/genai` со строгой валидацией схемы JSON Schema.
   - Каскадное переключение моделей (`gemini-3.8-flash` → `gemini-3.1-flash-lite` → `gemini-flash-latest`).
   - Обработка прерывания соединений со стороны клиента (`req.on('close')`).

3. **`feat(pwa): add Progressive Web App support, offline mode, and install prompts`**
   - Конфигурация `vite-plugin-pwa` со Standalone-манифестом и кэшированием Workbox.
   - Генерация полного пакета адаптивных иконок для Android и Apple iOS.
   - Интерактивные инструкции установки и баннер состояния сети.

4. **`feat(i18n): bilingual support for Russian and English languages`**
   - Реализация `LanguageContext` и типизированных словарей `translations.ts`.
   - Поддержка сохранения и восстановления языка из `localStorage`.
   - Локализация пресетов и аналитических подсказок.

5. **`feat(storage): integrate IndexedDB fallback and robust history management`**
   - Реализация `indexedDb.ts` для обхода ограничений квоты LocalStorage (`QuotaExceededError`).
   - Модальное окно истории `HistoryModal.tsx` с возможностью загрузки и очистки сохраненных решений.
   - Двусторонняя синхронизация истории при старте приложения.

6. **`feat(verdict): dynamic verdict synthesizer, editing mode and cycle prevention`**
   - Интеллектуальный синтез вердикта на основе фактических изменений аргументов и матрицы.
   - Режим редактирования и функция `getCleanBaseVerdict` для защиты от циклических ссылок.
   - Контроль соответствия языка отредактированного вердикта с возможностью быстрого пересчета.

7. **`feat(offline): explicit navigator.onLine check and client timeout resilience`**
   - Мгновенная проверка доступности сети перед отправкой fetch-запросов.
   - Бесшовное переключение на встроенный генератор без задержек и таймаутов.
